# Студенческие диски

## Запуск

Распакуй архив целиком. На Windows с Python 3.10 или новее открой `start-z.cmd`. Тот же вход из терминала — `python app.py`.

В аудитории положи четыре файла программы в отдельную папку, например `Z:\Практика`. При обычном запуске программа проверит родительскую папку `Z:\` и пропустит `Z:\Практика` целиком, включая её подпапки. Если диск отключён или у пользователя нет доступа, в результатах появится сообщение. Дома можно явно выбрать для проверки свою папку с существующими файлами.

```powershell
python app.py --root "C:\Мои файлы"
```

## Консоль и браузер

| Пункт меню | Действие |
| --- | --- |
| 1 | Сортировка по размеру, имени, типу или расширению. «Без сортировки» показывает файлы в порядке обхода |
| 2 | Фильтр, поиск по имени или пути, маска имени, расширения, размер от и до |
| 3 | Список файлов с именем, полным путём, типом и размером. Номер строки открывает действия |
| 4 | Повторная проверка диска |
| 5 | Изменение общих правил хранения с сохранением в `config.json` |
| 6 | Открытие веб-интерфейса с текущими параметрами поиска. Консоль остаётся доступной |
| 0 | Завершение программы и запущенного из меню веб-сервера |

Пункт 6 по умолчанию открывает `http://127.0.0.1:8765/`. Для запуска сразу в браузере выполни `python app.py --open`. Параметр `--port 8766` позволяет выбрать другой порт.

Консоль и браузер используют один индекс файлов. Изменение поиска или сортировки работает с этим индексом. На веб-странице кнопка «Параметры» открывает дополнительные условия. Разовый поиск действует в текущем интерфейсе. Сохранённые правила проверки применяются сразу в обоих режимах и при следующем запуске.

Удаление доступно для одного выбранного файла после подтверждения полного пути и выполняется без корзины. Если файл был заменён или изменился после проверки, программа предложит обновить список. Для первой проверки в аудитории выбери собственный тестовый файл.

## Диск и правила

Путь `..` в `config.json` означает папку на один уровень выше папки с программой. Можно указать и абсолютный путь, например `Z:\`. Приложение пропускает свою папку, когда она находится внутри выбранного источника. Для проверки самой папки программы укажи её явно через `--root .` из этой папки.

В браузере кнопка «Размер» открывает поля «От» и «До». Введи одну или обе границы в МБ и нажми «Применить». Указанные границы видны на кнопке. «Очистить размер» убирает границы поиска. В консоли используется пункт «Размер от и до, МБ» в параметрах поиска. Один мегабайт равен 1 000 000 байт.

Тип определяется по расширению. На Linux также учитывается бит исполнения у файлов без расширения. Для поиска ZIP, RAR, 7z и других архивных форматов выбери «Файлы-архивы» в списке фильтров.

Любое совпадение с правилом по размеру, типу, расширению или маске имени даёт статус «Подозрительный» с указанием причины. Чтобы увидеть такие записи, выбери фильтр «Подозрительные файлы» в браузере или консоли. Для имён доступны маски `*` и `?`. Добавлять файловые ограничения можно в пункте 5 или в окне «Правила» на веб-странице. Новые правила пересчитываются по уже собранным метаданным.

Чтобы отключить пометку по размеру, очисти поле «Помечать файлы от, МБ» в браузере или введи один минус при редактировании порога в консоли. Для удаления запрета по типу, расширению или маске убери соответствующее значение из правила. Поиск по размеру доступен при отключённой пометке по размеру.

Параметр `rescan_seconds` задаёт интервал фонового обхода в секундах. Значение `0` оставляет проверку при запуске и по команде. Для нескольких дисков добавь записи в массив `drives`. Корневые папки должны быть доступны учётной записи, под которой запущена программа.

## Запуск на сервере колледжа

В сетевой конфигурации укажи реальный путь общей папки или точку монтирования. На компьютере, где подключён диск, его сетевой адрес можно посмотреть командой `net use Z:`. Если у разных групп или пользователей разные сетевые пути, добавь нужные ресурсы в `drives`. Служба Windows может работать в другом сеансе, для неё удобнее использовать полный сетевой путь.

```json
{"name": "Студенческий диск", "path": "\\\\SERVER\\Students"}
```

Запусти `python app.py --serve` и задай пароль веб-пользователя `admin`. Для фонового запуска пароль можно передать переменной окружения `DISKMON_PASSWORD`. Сервер Waitress входит в комплект. Передай запросы с внутреннего HTTPS-адреса через IIS, nginx или другой обратный прокси на `127.0.0.1:8765`, сохранив заголовок Authorization. Открой внутренний адрес из браузера в аудитории.

[Сетевые диски и службы Windows](https://learn.microsoft.com/en-us/windows/win32/services/services-and-redirected-drives) · [Настройка Waitress за прокси](https://docs.pylonsproject.org/projects/waitress/en/stable/reverse-proxy.html)

## Файлы комплекта

Для запуска в Windows дважды нажми `start-z.cmd`. Исходный код программы находится в `app.py`, диски и правила заданы в `config.json`. В `resources.zip` лежат веб-страница, Flask с зависимостями и сервер Waitress. Устанавливать пакеты через pip не требуется. Лицензии библиотек находятся в папке `notices` внутри архива.

[Flask](https://flask.palletsprojects.com/) · [Исходный релиз Waitress](https://github.com/Pylons/waitress/tree/v3.0.2)
